Flight manual: how this dashboard works
  • Fuel gauge: total hours for the selected week against the 50-hour target, with the daily pace you still need.
  • Thrusters: each course has a 10.0-hour quota. Use ±0.5h to adjust, or click a thruster to aim the timer at it.
  • Cruise control: a course reaching 10.0h locks in. Move spare time to thrusters that are still low.
  • Timer: runs Pomodoro or stopwatch for the selected course. Finished focus sessions log themselves; "Log session" adds time early.
  • Syllabus: tick topics as you finish them. All data saves in this browser, so export a backup before clearing site data.
